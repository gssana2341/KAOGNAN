# KaoNgan · ระบบเช็คอินเข้างานด้วย QR

เช็คอิน/เอาท์ด้วยการสแกน QR ที่ทำงาน · แยกบัญชีรายคน · ขอลาออนไลน์ · ออก Excel · เลือกพื้นหลังน่ารัก ๆ ได้
ใช้ได้ทั้งมือถือและคอม (เว็บแบบ responsive + ติดตั้งเป็น PWA ได้)

## เริ่มใช้งาน

```bash
npm install
npm start          # เปิด http://localhost:3000
```

- แอดมินเริ่มต้น: `admin` / `admin1234` — ระบบบังคับให้เปลี่ยนรหัสผ่านตอนล็อกอินครั้งแรก
- อยากลองก่อนด้วยข้อมูลตัวอย่าง: `npm run seed` (พนักงาน 6 คน รหัสผ่าน `demo1234` พร้อมประวัติย้อนหลัง 4 สัปดาห์)
- ทดสอบอัตโนมัติ: `npm test`

## ขั้นตอนตั้งต้น (แอดมิน)

1. **จัดการ → ตั้งค่า & QR**: ใส่ชื่อบริษัท เวลาเริ่ม/เลิกงาน เวลาผ่อนผันมาสาย วันทำงาน
2. กด **เปิดหน้าจอ QR / พิมพ์** แล้วพิมพ์ไปติดที่ทำงาน (หรือเปิดค้างบนแท็บเล็ต)
3. **จัดการ → พนักงาน → เพิ่มพนักงาน** ตั้งรหัสผ่านชั่วคราวให้ พนักงานจะต้องเปลี่ยนเองตอนเข้าครั้งแรก
4. พนักงานล็อกอิน → กดปุ่มสแกนใหญ่ → เล็งกล้องไปที่ QR ที่ทำงาน (เข้างานและออกงานใช้ QR เดียวกัน)

## QR ที่ทำงาน — เลือกได้ 2 แบบ

| แบบ | เหมาะกับ | หมายเหตุ |
|---|---|---|
| **QR ติดผนัง** (ค่าเริ่มต้น) | ร้านเล็ก ๆ ที่ไว้ใจกัน | พิมพ์ครั้งเดียว แต่ถ้าใครถ่ายรูป QR ไปสแกนจากที่บ้านก็ทำได้ |
| **QR เปลี่ยนทุกครั้ง** | ต้องการกันการเช็คอินแทน/จากที่บ้าน | แสดงบนจอ/แท็บเล็ตที่ทำงาน QR เปลี่ยนทุก 15–600 วินาที (ค่าเริ่มต้น 60) |

“สร้าง QR ใหม่” ทำให้ QR เก่าที่พิมพ์ไว้ใช้ไม่ได้ทันที (ใช้เมื่อ QR รั่วไหล)

## กล้องมือถือต้องใช้ HTTPS

เบราว์เซอร์อนุญาตให้ใช้กล้องเฉพาะบน `https://` หรือ `localhost` เท่านั้น ถ้าเปิดผ่าน `http://192.168.x.x:3000` ปุ่มสแกนจะเปลี่ยนเป็น
“ถ่ายรูป QR แทน” (ยังเช็คอินได้ แต่ไม่ใช่กล้องสด) วิธีเปิด HTTPS:

- **ทดสอบในวง Wi-Fi เดียวกัน:** `npm run cert` (ต้องมี `openssl` — มากับ Git for Windows) แล้ว `npm start` ใหม่ → เปิด `https://<ไอพีเครื่องนี้>:3000` บนมือถือ ครั้งแรกกด “ขั้นสูง → ดำเนินการต่อ”
- **ใช้งานจริง:** วางหลัง HTTPS ที่ถูกต้อง เช่น Cloudflare Tunnel (ฟรี), Caddy, nginx + Let's Encrypt หรือโฮสต์บน VPS/Render/Railway
  (ถ้าอยู่หลัง proxy ตั้ง `TRUST_PROXY=1` เพื่อให้ตัวจำกัดการล็อกอินผิดเห็น IP จริง)

## Excel

**จัดการ → เวลาเข้างาน & Excel** เลือกช่วงวันที่ (และเลือกรายคนได้) แล้วกด “ดาวน์โหลด Excel” ได้ 3 ชีต:

- **สรุปรายคน** — วันทำงานตามกำหนด / มา / สาย (ครั้ง, นาที) / ลา / ขาด / ชั่วโมงรวม
- **รายวัน** — เวลาเข้า-ออกทุกวัน พร้อมสถานะ ปกติ·สาย·ลา·ขาด
- **ใบลา** — ใบลาทั้งหมดในช่วงนั้นพร้อมสถานะ

“ขาด” = วันทำงานที่ผ่านมาแล้วโดยไม่มีเวลาสแกนและไม่มีใบลาที่อนุมัติ · วันที่ใน Excel เป็น ค.ศ. (dd/mm/yyyy) ส่วนหน้าเว็บแสดง พ.ศ.
ลืมสแกน? แอดมินกดที่แถวในตารางเพื่อแก้เวลา/เพิ่มหมายเหตุได้

## การตั้งค่าผ่าน environment variables (ไม่บังคับ)

| ตัวแปร | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| `PORT` | `3000` | พอร์ต |
| `DATA_DIR` | `./data` | ที่เก็บฐานข้อมูล SQLite (`kaongan.db`) และรูปพื้นหลังที่อัปโหลด — **สำรองโฟลเดอร์นี้** |
| `TRUST_PROXY` | – | ตั้งเป็น `1` เมื่ออยู่หลัง reverse proxy |
| `CORS_ORIGINS` | – | origin ของแอปมือถือ (คั่นด้วย `,`) ที่อนุญาตให้เรียก API |
| `TZ_OFFSET_MIN` | `420` | เขตเวลา (นาทีจาก UTC) — ค่าเริ่มต้นคือประเทศไทย |
| `MIN_STAY_SEC` | `60` | ห่างกันอย่างน้อยกี่วินาทีระหว่างเข้า→ออก (กันสแกนซ้ำ) |

## โครงสร้าง

```
server/    Express + SQLite (better-sqlite3), API ทั้งหมดอยู่ใต้ /api (Bearer token)
public/    หน้าเว็บ (ไม่ต้อง build): js/views/* แต่ละหน้า, bg/* พื้นหลัง SVG, manifest + service worker
scripts/   seed-demo, make-cert, make-icons, copy-vendor
test/      ทดสอบ API ครบเส้นทางหลัก
```

## ต่อยอดเป็นแอป

เว็บเรียก API ผ่าน `Authorization: Bearer …` ล้วน ๆ ไม่พึ่ง cookie จึงห่อเป็นแอปได้ตรง ๆ (เช่น Capacitor):
ตั้ง `window.KN_API_BASE` ใน `public/config.js` เป็นที่อยู่เซิร์ฟเวอร์ และเพิ่ม origin ของแอปใน `CORS_ORIGINS`
แล้วค่อยเปลี่ยนตัวสแกนเป็นปลั๊กอินกล้องเนทีฟได้ถ้าต้องการ (ปัจจุบันใช้ jsQR ในเบราว์เซอร์)
